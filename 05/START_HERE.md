## ❓ FAQ

**Q: Which file should I use for my app?**
→ **Use `weatherwise-icon.svg` for modern platforms** (iOS 14+, Android 8+, Web). PNGs fallback for legacy.

**Q: Can I change the colors?**
→ Yes, edit `weatherwise-icon.svg` gradients. See `DESIGN_SYSTEM.md` for color codes.

**Q: Does it support dark mode?**
→ Yes! The deep blue gradient works on both light & dark wallpapers.

**Q: Why are there 3 sparkles?**
→ Visual distribution — top-right, bottom-left, right-center for balance.

**Q: Can I remove animations?**
→ Yes, delete `<animate>` tags from SVG, or use static PNGs.
